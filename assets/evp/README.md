# EVP — recording assets

- **Family:** hybrid (scripted tape + interactive live capture)
- **Modes:** interactive + scripted
- **Formats:** gif · svg · svgz
- **Converter:** none (native encoder)
- **Upstream:** https://github.com/HalFrgrd/evp

Files are named `<cell>-<scenario>.<ext>` within each format directory.
