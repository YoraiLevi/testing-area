# termsvg — recording assets

- **Family:** interactive (live TTY session)
- **Modes:** interactive
- **Formats:** cast · svg · gif · webm
- **Converter:** ffmpeg
- **Upstream:** https://github.com/mrmarble/termsvg

Files are named `<cell>-<scenario>.<ext>` within each format directory.
